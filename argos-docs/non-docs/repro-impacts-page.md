# Repro Impact's page

<details>

<summary>Columns reference</summary>

| Column         | Description                                                                      |
| -------------- | -------------------------------------------------------------------------------- |
| Name           | The name of the amplified ad, including its ad manager account and content type. |
| Status         | The current status of the ad, such as Paused.                                    |
| Meta Campaign  | The Meta campaign the ad belongs to.                                             |
| Meta Ad Set    | The Meta ad set the ad belongs to.                                               |
| Meta Ad        | The name of the Meta ad.                                                         |
| Objective      | The campaign objective, such as Traffic.                                         |
| Budget         | The budget set for the ad and whether it is Daily or Lifetime.                   |
| Spent          | The amount spent on the ad to date.                                              |
| Bid            | The bid amount and bid strategy, such as CPM.                                    |
| Clicks         | The total number of clicks the ad has received.                                  |
| Revenue        | The total revenue generated by the ad.                                           |
| Start-End Date | The ad's start and end dates, or Ongoing if no end date is set.                  |



</details>
