# Snapshot Forecasting (Test Feature)

{% hint style="warning" %}
This page describes a fictional feature for documentation testing.
{% endhint %}

Snapshot Forecasting predicts likely visual changes before a build runs. It uses recent screenshot history to flag screens that may need review.

### How it works

1. Select a branch in **Forecasts**.
2. Choose a viewport and a time range.
3. Review predicted changes before starting a build.

### Forecast confidence

Each prediction includes a confidence level:

* **High** — Similar changes occurred in recent builds.
* **Medium** — The screen changed across related branches.
* **Low** — The prediction has limited historical evidence.
